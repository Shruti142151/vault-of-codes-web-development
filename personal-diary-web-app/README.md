Personal Diary Web App

A diary-style web application developed using HTML, CSS, and JavaScript. The application allows users to write, save, and view diary entries through a simple and user-friendly interface.

Features

- Create and save diary entries
- View saved entries
- Simple and clean user interface
- Toggleable night mode
- Responsive design

Technologies Used

- HTML5
- CSS3
- JavaScript

Purpose

This project provided hands-on practice in frontend development, JavaScript functionality, DOM manipulation, user interaction, and responsive interface design.
