Responsive Internship Listing Website

A responsive internship listing website developed using HTML and CSS during my Web Development Internship at Vault of Codes.

The website presents internship opportunities through a clean, structured, and mobile-responsive interface.

Overview

The project was designed to provide users with an easy way to browse available internship opportunities and view detailed information about individual programs.

Features

- Responsive and mobile-friendly layout
- Clean and structured user interface
- Internship cards displaying:
  - Internship duration
  - Location
  - Start date
  - Stipend
- Individual internship detail pages
- Navigation between internship listings and detailed information
- Vault of Codes branding and visual elements
- Simple and user-friendly design

Pages

- Home / Internship Listings – Displays available internship opportunities.
- Java Internship – Provides details about the Java internship.
- Python Internship – Provides details about the Python internship.
- Web Development Internship – Provides details about the web development internship.
- Additional Information – Supporting page for internship-related content.

Technologies Used

- HTML5
- CSS3
