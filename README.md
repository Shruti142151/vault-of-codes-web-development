Vault of Codes – Web Development Internship

This repository contains projects developed during my Web Development Internship at Vault of Codes.

The projects provided hands-on experience in frontend development, responsive web design, JavaScript functionality, user interface development, and building interactive web applications.

Projects

1. Responsive Internship Listing Website

A responsive website designed to display internship opportunities in a clean and structured interface.

Features:

- Internship listing cards
- Internship duration, location, start date, and stipend information
- Individual internship detail pages
- Responsive layout for different screen sizes
- Clean and user-friendly interface

Technologies: HTML5, CSS3

"View Project →" (./internship-listing-website/)

---

2. Certificate Verification System

A web-based certificate verification project designed to provide a simple interface for verifying internship certificates.

Features:

- Certificate verification interface
- User-friendly design
- Structured certificate information
- Frontend-based implementation

Technologies: HTML, CSS, JavaScript

"View Project →" (./certificate-verifier/)

---

3. Personal Diary Web App

A diary-style web application that allows users to write, save, and view personal diary entries.

The application also includes a toggleable night mode for a more comfortable user experience.

Features:

- Create and save diary entries
- View saved entries
- Simple and clean interface
- Toggleable night mode
- Interactive user experience
- Responsive design

Technologies: HTML5, CSS3, JavaScript

"View Project →" (./personal-diary-web-app/)
